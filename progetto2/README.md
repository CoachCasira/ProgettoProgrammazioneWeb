# Gestione Numeri Telefonici - Secondo progetto

Applicazione Django per la consultazione operativa di numeri telefonici, SIM e chiamate.

Il progetto è la ristrutturazione del primo progetto di Programmazione Web con:

- Python 3.12;
- Django 5.2 LTS;
- PostgreSQL;
- Bootstrap integrato localmente;
- CSS personalizzato mantenuto dal primo progetto.

## Installazione rapida

Consultare:

```text
docs/MANUALE_UTENTE.md
```

Il backup PostgreSQL deve essere presente in:

```text
database/generated/progetto2_db.backup
```

Il file `.env` è locale e non deve essere caricato su GitHub.
